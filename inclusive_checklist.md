# Inclusive Content & WCAG Compliance Checklist

**Capstone 78 - Operational Standards**  
*WCAG 2.1 AA Actionable Checklist*

Educators and campus IT staff must verify each item before distributing educational materials:

- [x] **Alt-Text Verification:** Every informative graphic, diagram, and figure contains descriptive alternative text without redundant phrases like 'image of'.
- [x] **Audio & Video Captions:** Synchronized live or pre-recorded captions accompany all video lectures with speaker identification.
- [x] **Color Contrast Ratio:** Text meets a minimum contrast ratio of 4.5:1 against its background. Color is never used as the sole indicator of meaning.
- [x] **Semantic Document Hierarchy:** Heading structures (H1 -> H2 -> H3) are strictly maintained to allow sequential screen reader navigation.
- [x] **Full Keyboard Accessibility:** Interactive forms, buttons, and links are fully operable using the Tab and Arrow keys.
- [x] **Explicit Link Descriptions:** Hyperlinks clearly describe their target destination (e.g., 'Download Syllabus PDF') instead of generic text.
