# AI Accessibility Tool Test Log

**Capstone 78 - Empirical Benchmarks**

*Detailed Test Logs & Performance Matrix*

### Test Case 01 - Visual Alt-Text Generation (ChatGPT/Gemini)
* **Result:** Tested on 15 complex educational diagrams. Output achieved ~90% accuracy.
* **Notes:** Minor hallucinations detected on low-contrast charts. Required Human-in-the-Loop prompt refinement.

### Test Case 02 - Audio Synthetic Voice (ElevenLabs)
* **Result:** Tested on 20 academic textbook excerpts. Voice naturalness achieved 95% satisfaction score.
* **Notes:** Excellent cadence for vision-impaired students.

### Test Case 03 - Live Audio Captioning (Windows Live Captions)
* **Result:** Tested across 5 lecture recordings. Achieved 88% real-time transcription accuracy.
* **Notes:** Highlighted need for clear microphone input.

### Test Case 04 - Screen Reader Compatibility (NVDA & VoiceOver)
* **Result:** Verified PDF and Word document structures.
* **Notes:** Full compliance achieved when semantic headings and ARIA landmarks are present.
