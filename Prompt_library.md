**Comprehensive Engineering Prompts for WCAG 2.1 AA Compliance & Educational Media**

## 1. Overview & Usage Guidelines

This document contains the complete Master AI Prompt Library developed for Capstone 78 (*'AI-Powered Assistive Technology and Accessibility Guide'*). These standardized prompt templates are designed to assist educators, campus IT staff, and instructional designers in automating WCAG 2.1 AA compliance tasks across multi-modal educational materials.

---

## 2. Visual Alt-Text Generation Prompts

### 2.1 Scientific & Engineering Diagram Description

```
Act as an expert accessibility consultant. Analyze the attached educational diagram of [Insert Subject/Topic]. Write a concise, WCAG 2.1 AA compliant alternative text description under 150 words. Focus on the core relationships, directional arrows, and data flow shown in the figure. Do not include introductory filler words like 'This image displays' or 'Picture of'.
```

### 2.2 Historical Maps & Complex Visual Assets

```
Provide a detailed, screen-reader-friendly text alternative for the attached historical map/visual asset of [Insert Topic]. Describe geographical regions, color legend meanings, key annotations, and historical movement indicators sequentially.
```

## 3. Data Visualization & Quantitative Prompts

### 3.1 Bar Graphs & Statistical Charts

```
Provide a structured textual summary of the attached bar chart/graph showing [Insert Variables]. Explicitly state the x-axis label, y-axis units, highest data point, lowest data point, and the key overall trend. Ensure the output is formatted for seamless screen reader parsing.
```

### 3.2 Complex Data Tables & Financial Records

```
Convert the data in the attached image/table into a semantically structured Markdown table. Ensure proper row and column header tags are specified, and provide a 2-sentence executive summary above the table highlighting key metrics.
```

## 4. Lecture Audio & Media Accessibility Prompts

### 4.1 Lecture Audio Transcript Summarization

```
Summarize the attached lecture transcript into a clear 5-point bulleted study guide. Use plain language, clear semantic headings (H2 and H3 tags), and define all specialized technical terms immediately after introduction to assist students with cognitive learning needs.
```

### 4.2 Video Closed Captioning & Speaker Identification

```
Refine the attached raw speech-to-text transcript from a lecture recording. Insert accurate punctuation, fix domain-specific academic jargon errors, add clear speaker identifiers [Speaker 1, Speaker 2], and format timestamps every 30 seconds for SRT caption generation.
```

## 5. Document Structure & Compliance Audit Prompts

### 5.1 Heading Hierarchy & Structural Audit

```
Review the provided document text. Reformat the content using a strict, logical heading hierarchy (H1 for document title, H2 for major sections, H3 for sub-sections). Ensure all hyperlinked text is descriptive (e.g., 'Download Syllabus PDF' instead of 'Click Here').
```

### 5.2 Plain Language & Cognitive Accessibility Conversion

```
Rewrite the attached academic text into a clear, accessible version suitable for undergraduate students with cognitive learning disabilities or non-native English speakers. Maintain academic rigor while simplifying sentence structures and highlighting core definitions.
```
